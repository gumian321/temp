本项目复制 Release 内的 Godot 运行资源、原始美术检查场景、纹理、生成工具与历史检查材料；新增 `game/`、`tests/`、`docs/`。主场景切换为可玩场景，旧 `main.gd` / `main.tscn` 保留原样。历史 `previews/` 和 `verification/` 不代表本轮可玩版测试。

原车模由用户提供，原压缩包内未包含模型许可；本实现不扩大其原有授权。Noto 字体使用 SIL Open Font License，保留 `assets/fonts/LICENSE.txt`。
