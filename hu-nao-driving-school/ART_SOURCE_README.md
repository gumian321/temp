# 胡闹驾校 · 桑塔纳美术样片

这是围绕用户提供的 Volkswagen Santana CN-spec 1985 真实模型制作的小型 3D 美术场景。保留原模型的车身、轮胎胎纹、轮罩、格栅和外饰几何，没有使用程序化低模汽车替代。

## 打开

1. 使用 Godot 4.6 打开 `project.godot`，等待 GLB 和贴图导入
2. 运行 `main.tscn`
3. 按 1 查看整车，按 2 查看轮胎，按 3 查看驾驶舱；底部按钮提供相同视角切换

此项目只包含静态美术展示和视角切换，不含驾驶玩法、物理系统或联网。

运行时按 F12 可依次保存三个真实视口及本机诊断 JSON；结果写入 `previews/` 和 `verification/`。这会短暂切换镜头。

## 资产与可编辑源文件

- `car/Santana_Refined.glb`：用于 Godot 的真实车辆及补充内饰
- `source/Santana_Refined.blend`：可编辑车辆，Blender 4.3.2
- `source/Santana_Art_Slice.blend`：包含驾驶校场景的 Blender 预览场景
- `source/original/`：未修改的原始 OBJ 与 MTL
- `environment/`：可重建的驾驶校环境、材质、标识及互换 GLB
- `assets/textures/`：本次制作的仪表、收音机、空调控制、织物等细节贴图
- `tools/`：贴图生成、车辆细化和预览渲染脚本
- `previews/`：Blender 预览及真正的 Godot 运行视口截图；文件名明确区分 Blender / Godot
- `verification/godot_runtime_report.json`：当前云端图形验证的渲染器、视口和逐视角抽样数据

## 已补充的内饰

在原始车舱轮廓上加入模拟仪表刻度和指针、收音机频段和磁带槽、实体旋钮、滑杆空调面板、出风口叶片、手套箱锁扣、机械挡杆、织物座椅和缝线，并区分塑料、皮革、织物、橡胶和金属的粗糙度。

补充部分采用克制的老式汽车设计语言，是美术化完善，并不宣称是对特定年份内饰的考据复原。

## 视觉方向

酒红色旧款车身、柔和暖光、较冷的环境补光、玉绿与米色驾驶校建筑、细叶植被。Godot 的车漆使用柔和分层的卡通漫反射、克制的清漆反射和边缘亮度；轮胎以局部补光凸显原有胎纹。仪表、收音机和滑杆面板采用轻微自发光补偿，提高阴影下的可读性。其他材质保留不同的反光和粗糙度，原车精细轮胎和外饰继续保留。

当前一轮采用 ACES 高光压缩、提高白点、局部冷色补光、温暖墙面与橙色路锥、较深自然绿植、细微距离雾和接触遮蔽。植被叶片减少高频噪点，墙脚增加克制的色调变化。没有用图像后期修改实际截图。

## 验证范围

- 原 ZIP 的完整大小、SHA-256 与 Git LFS 一致，压缩包完整性检查通过
- 原始 OBJ 已在禁用自动执行脚本的 Blender 环境中导入
- Godot 4.6.3 的资源导入、主场景脚本解析和无界面启动已测试
- 已在云端 Linux 桌面实际启动 Godot 4.6.3，运行 X11 / OpenGL Compatibility 图形视口并验证整车、轮胎、驾驶舱三个视角
- `previews/Santana_*_Godot_Verified.png` 是运行中的 Godot 视口直接保存的图片；当前图片像素为 1354 × 846，项目逻辑视口配置为 1600 × 1000（嵌入窗口缩放后输出尺寸不同）
- 云端图形设备为 Mesa llvmpipe 软件渲染器。报告里的 FPS 是云端静态场景单点抽样，不代表独立显卡或用户电脑性能
- 已降低主光强度、控制高光，微提轮胎材质亮度，并提高阴影深度精度与过滤质量；仪表台阴影仍保留自然遮挡，并非无阴影展示
- 预览中的 Blender 灯光和 Godot 的卡通材质不是完全相同的渲染系统
- 第三轮精修位于 Godot 的运行时材质、灯光和环境脚本；Blender 源文件与 Blender 预览保留原有美术创作状态，没有伪称为同一套渲染结果

## 重建资产

先运行 `python3 tools/make_detail_textures.py`，再用 Blender 运行 `tools/refine_santana.py`。纹理生成脚本使用 Pillow 和 NumPy。环境重建及 GLB 导出方法见 `environment/README.md`。
