# 胡闹驾校 · 两人局域网最小可玩版

Godot 4.6.3 / Windows x64 优先。一个学员驾驶，同一辆 1985 燃油桑塔纳的右座固定坐教练。

## 两个人怎么玩

1. 两台电脑连接同一局域网，各自解压运行 `HuNaoDrivingSchool.exe`，无需安装 Godot。
2. 房主选择自己的角色，点击 **建房**。把房间底部显示的内网 IPv4 地址告诉同伴。
3. 同伴输入该地址，点击 **加入房间**。房主看到两人就座后点击 **开始**。
4. 学员怒气打满 100 获胜；教练撑过 5 分钟获胜。结算后房主点 **重新开局**。
5. Esc / 返回房间会断开连接。客人离开后房主房间继续等人；房主离开后客人回到菜单，可重新加入。

使用 ENet UDP 27850。只支持两人局域网，不含互联网服务、路由穿透或四人模式。若连不上，核对内网 IP、是否在同一网络、网络是否隔离客户端；本项目不会修改防火墙、VPN 或系统安全设置。

| 角色 | 操作 |
| --- | --- |
| 学员（左座） | W/S 前进／倒车，A/D 转向，空格刹车 |
| 学员整蛊 | 1 摇汽水、2 扔纸飞机、3 掰后视镜；每次消耗 20 灵感，共用 8 秒冷却 |
| 教练（右座） | 空格副刹（连续最多 3 秒，松开恢复）；前摇内按 1 接汽水、2 拦飞机、3 护镜 |
| 教练修复 | 按住 R 1.5 秒，清理汽水／纸飞机并复位镜面；不会消除已获得的怒气 |
| 两人通用 | V 切换本角色座位／追车视角；Esc 退出连接 |

起始灵感 40。安全行驶速度超过 2 m/s，每秒获得 4 灵感，最多 100；撞车不直接加怒气，暂停灵感收入 3 秒。三种前摇分别 1.6 / 1.25 / 1.8 秒，首次命中怒气 22 / 27 / 32，同种整蛊后续收益按 `基础值 / (1 + 0.5 × 已命中次数)` 衰减。教练错误反制也有 0.65 秒冷却。

**单机演示**按钮不联网，Tab 在学员／教练之间切换。它不能代替双人联机。

## 源码与美术

打开本目录的 `project.godot`，首次等待资源导入，F6/F5 运行可玩主场景 `game/play.tscn`。原始美术检查场景 `main.tscn` 保留，键 1/2/3 检查整车、轮胎、驾驶舱；它是旧红色 v3 样片，不含玩法。

可玩版本保留原始 GLB（1,096,869 三角面）及精修内饰贴图，增加白红驾校涂装、胡闹驾校字样、虚构黄色学牌、左右前翼子板带支架圆形辅助镜和副刹踏板。三角面不做隐性删减，启动时按材质批处理不透明网格，透明玻璃保留独立排序。镜子使用装饰环境色，**不是实时后视镜**；初版车轮尚无独立滚动／转向动画。环境碰撞采用简化边界与三个练习岛，非精细网格碰撞。

原美术源码、Blender 文件和授权来源说明见 [ART_SOURCE_README.md](ART_SOURCE_README.md) 与 [docs/SOURCE.md](docs/SOURCE.md)。大 Blender 文件留在已授权的原 Release，没有新增 LFS 指针。

## 性能与平台边界

勾选底部“轻量”会降低 3D 分辨率至 65%、关闭阴影和 MSAA，不削减车辆几何或内饰。中文 UI 使用随包 Noto 字体，不依赖操作系统字体。

云端只有 llvmpipe 软件渲染，实测依然较慢，**不能承诺实机稳定 60 FPS**。功能、网络和 GPU 性能是三类独立验证，实际测量及未测项见 [docs/TEST_REPORT.md](docs/TEST_REPORT.md)。Windows/macOS 包为交叉导出，未在对应实体系统上运行；Linux 导出包在本环境启动验证。macOS 未签名／未公证，不作为首版阻塞项，不提供绕过系统安全设置的脚本。

## 开发验证与导出

```sh
godot --headless --editor --path . --import
godot --headless --path . --script tests/test_rules.gd
python3 tests/run_network.py
# 构建前安装 Godot 官方 4.6.3 export templates，并创建 builds 下的目标目录。
godot --headless --path . --export-release Windows
godot --headless --path . --export-release Linux
godot --headless --path . --export-release macOS
```

网络设计、速率与限制见 [docs/NETWORK.md](docs/NETWORK.md)。测试使用真正两个 Godot 进程；延迟丢包通过普通 UDP 用户态代理注入，无管理员权限。测试结果写在被 git 忽略的 `tests/results/`，本轮归档证据保存在 `docs/evidence/`。
