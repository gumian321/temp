虫器官武装重新设计

本次把旧枪械名称、剪影和图标重做为虫体器官。游戏内名称以 data/insect_armaments.json 为唯一来源，简体中文和英文同步。内部 Core / Turret / projectile ID、存档引用及原始资源表数值保持原样；本图集映射不改变它们。

33 个独立身份：12 种射击器官、2 种布卵器、3 种虫巢、6 种辅助器官、4 种部署虫体，以及 6 种强化器官。前三张生图透明图集按 3×3 排列，第四张强化器官图集按 3×2 排列；实际 AtlasTexture 区域按图片内容校准，避免机械等分截断尖角。图片原文件不经过裁切重写，UI 和战斗等比绘制。

A：蜂尾针簇 / 裂颚 / 爆腹；刺冠 / 穿喙 / 雷须；缄鸣 / 炽嗉 / 追蛹。
B：王卵 / 振翅 / 螳涡；卵环 / 播卵 / 猎蜂巢；缝蚁巢 / 拾蚁巢 / 鞘盾。
C：缝生蜱 / 蜜囊 / 隐翅；铁鞘 / 孵囊 / 裂卵；猎蜂 / 缝蚁 / 拾蚁。

统一入口 scripts/insect_armaments.gd 通过现有 SourceDB 的 sprite/core_sprite/reward_sprite 生效。头部、装配、奖励、研究、战斗和敌方引用同一映射；辅助虫体也覆盖。原 Brood.weapon_texture 调用同步转向新图集，敌虫物种贴图保持现有入口。

说明文字与当前机制同步，不附加毒伤或腐蚀等未实现效果。旧英文 UI 文本映射到新名称；虫巢与飞出虫体有独立名称。研究奖励描述统一引用新器官描述，修复原连射武器描述 key 多余空格导致的缺失。

验证：tests/test_insect_armaments.gd 检查名称、描述、核心覆盖和未改动战斗数据。tests/test_insect_art_routes.gd 检查 33 个图集区域、颜色、透明度、等比尺寸以及各入口引用。图集生成、实际像素检查和界面截图由总体验证记录补充。

D：裂刺囊 / 爆腺 / 贯针；跃电脉 / 巨腹 / 统御触角。六种强化器官保留原 chipType 和所有数值，替换原方形芯片图标、名称与说明。

同期控制机制更新：缄鸣对无护盾的普通移动敌人施加 0.8 秒缚丝，移动速度降低 65%，不中断射击。雷须保留连锁伤害，并短暂向发射器官牵引合格目标。控制不可叠加，首领、固定及特殊任务目标免疫；具体上限、恢复期与测试见控制系统验证记录。
