第十轮：密集战斗性能优化（2026-10-14）

基于用户提交 2e979236680e17349fd13aff6430d372cc97a334。
保留该版水晶掉落、软体器官、鞭毛融合、环形阵列、直接装配和全部美术。
不减少敌人、弹体、武器伤害/射程/频率或关节动画数量来制造性能收益。

已实施
1. 补齐均匀网格空间索引：无限距离精确寻敌、有序范围/扫掠碰撞、
   友军与护盾提供者预筛、UID查找、位移/召唤/帧间替换的索引维护。
   保留同距目标的数组顺序、穿透/护盾/死亡目标和命中位置原有语义。
2. 软体求解保持120Hz子步、积分和约束顺序。精确平衡且未受击的晶格
   不重复求解，受击立即唤醒；活跃晶格减少字典写回、数组及指数计算。
3. 虫腿/触角/翅膀合并成GPU骨骼蒙皮Polygon2D：每点原骨骼权重1，
   保持刚性关节。身体软体骨架独立保留；没有逐帧CPU顶点变换/上传。
   合批保持纹理、绘制顺序、受击材质、死亡透明度，增加保守边缘剔除范围。
4. 器官网格缓存UV/拓扑/静态形变项，只更新动态顶点缓冲；原生GL逐像素
   与原版对照通过。离屏敌人rig复用，隐藏LRU上限96，屏内与可见死亡反馈
   不受此上限限制，移除/重开战斗正常释放。
5. 敌弹精确轮廓缓存，避免重复类型解析；特效线性稳定分类替代多次过滤
   和字典成员遍历。装饰预算、敌弹可读性、基础绘制内容保持不变。
6. 粒子不可变配置/曲线预计算缓存；保留数量、寿命、Tween和跟随清理。
7. HUD仍每帧读真实数据，仅变化时重绘/改主题/测字；字号、主题、尺寸、
   语言与换行改变仍重新适配。无人机计数单次遍历，炮塔使用直接索引。

选择依据及未采用方案
- 当前场景为持续移动、尺寸相近的敌人和稀疏无限战场，扩展已有均匀网格，
  不为采用四叉树而重新引入树分裂/合并。保留可重复密度基准供后续判断。
- 共享空闲ShaderMaterial实测没有减少骨架drawcall，未加入无收益切换。
- CPU逐帧合并附肢虽减少drawcall，但会增加顶点变换成本；最终采用GPU骨骼
  方案，移除这条CPU更新路径。试验脚本仅用于诊断，不在默认游戏中运行。
- 单项微基准不等于整场FPS；正式整场配对数据与运行方法见下方最终证据。

兼容修正
- 直接装配旧UI帧遇到角色/模块已变化时，安全跳过已失效的姿态，避免越界。
- 更新既有蜘蛛地雷测试的过时fixture，使用真实MinesCore及slot，未改变玩法。

验证与性能结果
- 85/85套唯一功能回归通过（84默认+enemy_motion），含最终GPU合批、
  96隐藏缓存、空间oracle、保留用户新功能的回归。
- CPU三对交替运行，固定seed/dt/实体压力，9个前后场景的状态签名与
  实体分布全部严格一致，三轮源码hash稳定、fixture hash相同。
- 三轮中位数，单位ms（before -> after）：
  低密度 p50 16.698 -> 8.852（-47.0%）；p95 27.402 -> 14.446（-47.3%）。
  中密度 p50 53.279 -> 31.184（-41.5%）；p95 114.481 -> 55.080（-51.9%）。
  高密度 p50 245.945 -> 141.827（-42.3%）；p95 352.613 -> 244.558（-30.6%）。
- 可采集进程CPU累计的第2/3对，实际user+system CPU下降40.9%/47.9%；
  该指标包含启动、预热和补弹，不是单帧CPU。第1个before未采集，不补造。
- 首对出现秒级耗时峰值，不能直接归因于外部调度；其余两对未重现多秒极峰，
  但高密度仍有明显长尾。剩余最大热点是projectiles阶段；不保证极端密度60fps。
- 原生渲染三对：每对的drawcall p50都为3938 -> 2285（-41.98%），
  p95都为4351 -> 2693（-38.11%）。六次状态签名、实体分布完全相同。
- 描述性三轮median frame p50 263.725 -> 238.892ms（-9.42%），
  p95 697.048 -> 554.723ms（-20.42%）。但第2对整帧与总CPU回退，
  第3对p95回退，不能称为稳定的整体帧率改善。原生进程CPU中位下降5.03%。
  原生测试为llvmpipe软件GL，驱动不保证关闭vsync；不可外推用户Windows显卡。
  此fixture原生粒子发射器计数为0；粒子缓存收益另由专项等价/创建CPU测试证明。
- 三对整场PNG均仅0.002527%颜色通道变化，最大2/255、无>10差异像素。
  正式证据：docs/test-evidence/dense-combat-paired-round10.json、
  dense-render-paired-round10.json、round10-regression-final-report.json。
- 最终隔离Godot editor import零ERROR，Python工具编译和git diff --check通过。
- 最终GPU附肢6物种动态对照：普通状态168 -> 12 drawcalls；受击204 -> 48。
  正常/移动/受击/死亡/屏幕边缘图像最大颜色通道差不超过2/255，原关节保留。
