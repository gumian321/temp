浅色 UI、清晰字体与命中反馈修订

用户反馈
上一版深色仪表盘与浅色战场割裂；字体过细；程序绘制的装饰图标不足以满足美术要求；悬浮说明白底白字；命中反馈总在中心且形状/大小单一。

本轮更改
1. 全局米白/象牙底、深蓝文字，青绿与琥珀仅作状态强调。新生成浅色蜈蚣首页背景，与战场统一明度。
2. 16 个生成式虫甲 UI 图标、四种生成式面板/按钮皮肤、一条单独生成的简洁 HUD 轨道。以 AtlasTexture 与正确的九宫格边距接入，不以程序几何图形冒充生成资产。功能性进度条和布局仍由引擎实时计算。
3. Noto Sans CJK SC Bold，字重700。使用系统合法安装字体提取并子集化，包含现有项目文字及 GB2312 常用汉字；保留原完整字体作未知字符后备。许可与重建方法随字体保存。
4. 战斗 HUD 去掉大黑块和五个环形仪表，采用贴边的生命/燃料条、小计时与威胁指示、紧凑体节/蜂群计数。没有燃料箱时不占用燃料条空间。
5. TooltipPanel 与 TooltipLabel 成对显式设置，暖白背景、深蓝文字；保留引擎原生悬浮布局和键盘焦点。
6. 命中位置根据投射物运动线段与目标表面求交，兼顾偏心命中、快速弹丸、护盾和光束。命中强度根据伤害有界缩放，使用短促的定向火花/碎屑，移除重复的花状覆盖层。视觉合并与数量限制不改变伤害和随机数逻辑；体节毁坏反馈单独保留。

均使用内置图像生成工具生成，保留原 PNG。图标/面板提示要求透明通道、独立完整轮廓、无文字、象牙虫甲和深蓝描边；轨道要求无尖刺/高耸装饰，避免小尺寸变形；首页要求浅色纸感、低噪点和清晰主体。具体运行时裁切区域由生成式 UI helper 定义。

验证
新增 generated_light_ui、tooltip_theme、contact_impacts；纳入默认回归集合。实际引擎截图覆盖多个窗口尺寸、悬浮状态、浅色全界面、弱/重偏心命中。测试同时检查实际 TextureRect 边界，以避免仅测布局框而忽略贴图原始最小尺寸的问题。
