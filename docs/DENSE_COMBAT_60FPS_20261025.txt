密集战斗性能优化 — 2026-10-25

结果与使用
本轮继续优化怪群和密集弹幕，保留当前素材、手绘风格、动态拖尾、发射光晕、受击形变与死亡效果。
没有降低射速、弹量、敌人数、模拟频率或现有画面细节；OpenGL compatibility 仍是默认渲染器。
源码和 Windows Release 试玩 EXE 已更新：artifacts/dense60-release/RunBuildPew.exe。
可以直接运行该 EXE，或停止旧运行后从 Godot F5 重开。正常启动仍使用正常游戏规则。

密集压力测试确认有明显收益，但极端负载仍达不到 60 FPS。80 秒自然波次实战的慢帧也尚未消除。
以下区分固定步长的补弹压力场景与实际时间推进的正常主场景，不把压力测试数字当作整局 FPS。

实现
1. 敌方弹体保留原生绘制命令，只更新位置和角度。
   膜、核、边线和抗锯齿均保留原来的绘制方式；不重建每一颗弹体的相同几何。
   共用原有材质，按弹体身份复用 CanvasItem；离屏隐藏，退役对象池最多 96 个，退出场景释放。
2. 密集发射效果使用共享网格和 MultiMesh，着色器执行原有五条墨带、光晕、渐隐与抛壳公式。
   同屏可见发射效果达到 12 个才启用；稀疏时继续使用原有路径，避免批处理固定成本。
   超出批容量时回到原路径，不丢弃效果。暂停时间仍由游戏控制。
3. 多节虫体面对至少 3 颗敌弹时建立本帧身体空间索引。
   先筛选扫掠线段附近的身体，再执行原来的精确距离测试，保持首个命中部件顺序和碰撞半径。
   少量部件或稀疏敌弹继续直接扫描；死亡、隐身、护盾与伤害条件仍即时判断。
4. 每个战斗 tick 复用护盾部件索引；没有芯片时跳过反复寻找邻接芯片。
   索引不跨 tick 缓存，部件销毁、主体武器替换与芯片失效仍使用本帧状态。
5. 护盾目标按原优先级排列后才做墙体射线，复用同次查询已经得到的可见性。
   同分顺序、护盾优先和特殊雷达语义保留；随机雷达仍走原 RNG 路径。
6. 怪物骨骼只提交改变的可见性、材质和颜色，避免一次骨骼姿态重复设置同一属性。
   已使用原有远距简化显示的怪物，稳定 0.2 秒后将隐藏的完整骨骼树移出活动树。
   原节点、足肢与材质都保留；靠近、受击和死亡立即恢复，不改变原有简化显示条件。

固定负载压力结果
本机 NVIDIA GeForce GTX 1050，Godot 4.6.3 Release，1440×900，原生 OpenGL。
同一个 EXE 用环境开关交替走原路径和优化路径，均独立临时存档、无编辑器调试器、关闭垂直同步。
AI、武器、碰撞和绘制为生产代码。每帧模拟固定 1/60 秒，60 帧预热后统计 180 帧。
测试将玩家和怪物生命提高，并补足弹体数量，目的是持续制造压力；这不是正常开局，也不是自然时间 FPS。
弹体补足发生在每帧模拟之前，采样时的实际弹数会因命中或消失稍低于配置下限。
补弹注入、模拟、绘制、显示同步和整帧耗时分别记录，没有将暂停、奖励界面算成战斗帧。
测试窗口在屏幕外使用原生渲染；实际前台、驱动和不同硬件的结果可能不同。

较早的四轮交替复测（原路径 / 优化 / 优化 / 原路径，之后仅增加稀疏负载门槛与骨骼停用延迟）：
32 怪两轮均值：38.65ms → 28.88ms，平均 P95 45.15ms → 34.44ms。
64 怪两轮均值：72.14ms → 45.02ms，平均 P95 82.66ms → 49.11ms。
各轮耗时有较大波动，因此不承诺某个精确百分比适用于所有机器或战况。
相同压力配置的平均弹量与特效量接近，但终态弹数和伤害也有少量差异；同一开关重复运行也存在差异。
压力脚本不是逐帧确定性判定器，不声称上述前后是每个像素、每颗弹体都完全相同的画面。

最终压力复测的主要 CPU 分项：
32 怪：主绘制 21.18ms → 11.59ms；弹体绘制 8.60ms → 3.72ms；发射效果 2.82ms → 0.43ms。
64 怪：主绘制 65.03ms → 23.79ms；弹体绘制 28.52ms → 10.06ms；发射效果 9.56ms → 1.03ms。
这些分项来自轻量插桩，主绘制按主场景原有计时段求和，不包含所有子 CanvasItem 的底层提交时间。
整帧结果仍包含原生渲染等待和子节点工作，不能只用 CPU 分项推算稳定 60。

真实时间实战结果
同一 Release EXE，正常主场景、原生帧间隔、原波次、实际 AI/开矿/碰撞/音效和显示，80 秒。
使用屏幕外原生窗口采样；不是编辑器运行，也不是前台人工操作测试。
使用 11 节混装的隔离测试组合，并保住玩家部件、抑制奖励中断以持续采样；敌人正常受伤和死亡。
最终运行记录 66～106 个 actor，场上弹体峰值 25，不属于 256 弹体压力场景。
                                 平均帧耗时    P95       ≤16.67ms 帧比例
原路径                           14.98ms      20.56ms     75.06%
首版优化（尚未加自适应门槛）     15.21ms      21.69ms     68.21%
最终优化                         15.06ms      21.37ms     75.70%
最终第 70～80 秒                  15.67ms      20.36ms     72.91%

首版长时间实战更慢，随后增加稀疏效果门槛和隐藏骨骼停用延迟；最终恢复到与原路径相近的整体表现。
实际帧间隔会影响模拟与交战过程，这三轮不是完全相同战况，不能据此声称整局 FPS 有显著提升。
最终平均帧耗时虽在 60 FPS 预算内，约四分之一帧仍超预算；极端压力也超出 16.67ms。
因此本轮完成的是密集渲染与碰撞热区优化，尚未实现全程稳定 60 FPS。
后续剩余压力主要是大量动态拖尾/受击效果、原生绘制提交、怪群 AI 与岩壁查询。

840 组锁敌优先级、遮挡、护盾、随机和同分顺序与原实现一致。
240 颗弯曲弹体在 0.5 / 1 / 1.65 倍缩放做原路径画面对照，最大平均通道误差约 0.00242 / 255。

原生渲染验证使用隔离临时用户目录；未修改正常玩家存档。既有 Windows 证书库告警单独保留。
