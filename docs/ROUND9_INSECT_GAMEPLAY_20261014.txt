第九轮：双虫角色、直接身体装配与战斗表现（2026-10-14）

同步基础
修改前从 121e00f 快进到用户最新 1a671cb73f504fe55e6c8de7f68144c41474c70f。保留 Windows 体验包、隔离测试入口、Debug 解锁能力、存档及音频/光标退出清理；按新双角色要求更新相关入口与测试，不覆盖用户无关改动。

1. 屏幕稳定
连续开火、命中及爆炸原先驱动全场高频位移，纸面细纹和地形一起跳动。修复前原生 100 帧测试峰值相邻帧位移约 3.04 像素。取消普通攻击的全屏振荡，保留局部炮口、后坐、命中和破坏反馈；受伤仅有平滑、受限的小幅位移。粒子层在最终镜头位置确定后同步，避免世界与特效错一帧。

2. 开局镜头
六种任务开局立即跟随玩家，取消开局目标/首领巡视。旧 skip_boss 设置不会恢复这段开场；后续新出现的首领事件仍按原规则处理。

3. 渐进盘绕
蜈蚣从当前真实身体姿态逐节收拢，约 0.95 秒进入盘绕；技能结束约 0.8 秒逐步展开。原 2.4 秒技能时长和冷却保留。渲染、炮口和碰撞共享动画中的实际身体位置；暂停冻结，损毁、调整顺序和重开安全处理。

4. 两个可选角色
虫巢只展示蜈蚣和蜘蛛，Debug 解锁及 Windows 检查同步改为双角色。旧存档若选中甲虫则安全回到蜈蚣，不清空研究、货币、任务、蓝图或历史记录。首领击杀统计保留，不再触发甲虫解锁提示。

5. 直接拼接身体
装配画布直接显示生成的角色身体、腿节和末端。待装部件以图标置于底部，拖到身体上的增加位置即可插入/生长；拖动已装模块交换位置。可缩放、平移和一键看全身，保持无效投放不丢库存。取消原来的装配卡牌/腿行布局，预览不推进实际战斗姿态。

6. 虫类弹体
新增透明生成图集，采用螫针、颚刃、酸囊、刺荚、追踪幼虫、虫卵、花粉珠、旋孢和翅种等轮廓；移除旧工业炮弹/导弹图层。弹道行为和伤害不变，拖尾及爆破改为花粉/孢子/酸液表现，敌方弹体保留明确识别提示。新图集兼容源码首次拉取时尚未导入的情况。
