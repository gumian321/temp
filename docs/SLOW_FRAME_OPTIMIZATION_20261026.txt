飞行弹体与拖尾
原有绘制已经缓存部分几何，但仍逐颗提交三角条带和贴图，密集时原生提交与绘制调用仍偏高。
现在使用共享静态网格和实例数据，成批提交原有条带和生图弹体。
曲线仍使用相同历史位置、裁剪、30Hz 交错几何缓存和逐帧弹头更新；波动、渐隐、颜色、缩放和朝向公式保持原样。
原有 96 条详细友方尾迹等显示规则没有改变；敌弹、余尾及支持无人机保留各自原有层次。
批次直接插入原材质命令流；遇到其他原生绘制命令就结束该批次，保留交叠与遮挡顺序。
飞行数据最多 768 个槽，材质命令组最多 96 个；超过容量时回退原路径，任何弹体或效果都不会因此消失。
数据、共享网格和管线在已有加载预热阶段准备；没有为每颗子弹创建 Node、材质或独立纹理。

小批量的真实开销
相同脚本轨迹的移动弹体原生渲染测试，原路径 / 合批 / 合批 / 原路径交替，分别预热 20 帧、采样 60 帧。
这只测弹体呈现，不包含游戏 AI、挖矿、碰撞，不能当作整局 FPS。
4 颗：1.56 → 1.66ms；12 颗：1.79 → 2.14ms；32 颗：3.03 → 3.67ms；
64 颗：4.33 → 4.07ms；240 颗：15.63 → 13.98ms。
小批量启用实例化会增加固定成本，因此正式游戏只在同屏可见弹体达到 64 颗时使用新路径。
计数使用与原裁剪相同的 220px 余量；少量交火和离屏弹体不会强行触发合批。
支持无人机的独立尾迹继续走原路径，避免在其身体与尾迹交替的命令流里创建无收益的小批次。

怪物完整骨骼复用
同种解剖结构、同张贴图的怪物复用完整骨骼、足肢、皮肤网格和材质，最多保留 32 套。
池内节点移出 SceneTree，不提交隐藏更新；换局和销毁图层会释放它们，包括已经停用的外部骨骼树。
新怪物重新绑定自己的状态，重置步态、足端、朝向、回弹、颜色、受击材质和死亡状态，不继承上一只怪的姿态。
不改变原有远近显示、受击恢复、死亡时长或可见怪物数量。
暖素材缓存的 36 次准备对照：完整新建平均约 2.28ms，复用约 0.26ms；P95 约 2.87 → 0.33ms。
这是单只骨骼准备耗时，不是整场帧率。普通六种虫和三种特殊贴图在移动、受击、远近切换、死亡中通过像素对照。

碰撞与升级查询
空间索引缓存同一网格范围的候选表，最多 128 项；重建索引或任何实体跨网格时立即失效。
缓存只复用成员和原顺序，候选仍引用活的实体状态；生命、隐身、护盾和实际距离继续即时检查。
返回独立数组，调用者修改容器不会污染缓存。
6,000 次带负坐标及移动的查询与全扫描网格判定一致；2,400 次重复范围查询约 18.45 → 1.52ms。
这只是查询微测试，不以其百分比宣传整场帧率。
升级加成在单次战斗 tick 内按部件 ID/字段复用，保持原求和顺序；新 tick、刷新升级立即清空。
覆盖所有 62 个实际 Core 与七种升级字段；没有升级时直接返回原本的零加成。

性能测量口径
本机 NVIDIA GeForce GTX 1050，Godot 4.6.3 Release，1440×900，OpenGL compatibility，屏幕外原生窗口。
所有比较使用独立临时用户目录；测试运行串行，未同时运行其他本轮测试或导出。
环境中另有 Godot 进程，未关闭不属于本轮测试的进程；结果受本机负载与调度波动影响。
固定压力：同一 EXE，原路径 / 优化 / 优化 / 原路径交替，每轮预热 90 帧、采样 360 帧，保留每轮原始数据。
基线是上一版已经优化过的路径；本轮四个开关在基线为 1、优化为 0，之前六个优化开关均保持为 0。
固定压力使用生产 AI/武器/碰撞/绘制，但提高测试生命，每帧模拟前补足弹体；采样时实际弹数可因命中而略低。
模拟固定 1/60 秒，墙钟统计注入、模拟、提交、渲染与等待的整帧耗时。固定步长不是实际 60 FPS。
主场景实时对照：80 秒、11 节混装、自然波次、原生帧间隔，保住玩家部件并抑制奖励中断以连续测量。
真实帧间隔会改变交战过程；两轮实战不代表逐帧完全相同的战况，不将差值解释为严格因果百分比。
本轮始终保留各轮 P95/P99 和峰值，绘制调用减少不代表极端负载已经达到 60 帧。

最终交替压力结果
下列为两轮均值；P95/P99 是各轮分位数的平均值，不是混合样本重新求分位数。
配置                    平均帧耗时              P95                    P99
32 怪 / 128 弹体 / 13 部件  30.07 → 25.97ms       40.46 → 32.08ms        49.22 → 36.45ms
64 怪 / 256 弹体 / 31 部件  52.07 → 51.06ms       63.65 → 66.69ms        72.31 → 79.04ms
绘制调用分别约 1480 → 1252、2467 → 2102；各轮实际弹量和效果数量保持接近。
32 怪配置 P99 下降约 26%，但重负载 P95/P99 没有可靠改善，后两轮甚至偏高。
这两种压力都超过 16.67ms 预算，不宣传极端弹幕已经流畅 60 FPS。

真实时间实战的两轮对照

仍需处理大量角色/特效同时更新、绘制提交与岩壁相关工作；本机后台负载也影响尾部帧耗时。
完整保留四次实战及两版交替压力，不以较好的某一次代替最终实测。
