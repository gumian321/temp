性能与显示优化 — 2026-10-25

本次范围
保留首页与出击页已有的黑白生图、透明图标和手绘风格，优化运行时绘制、HUD 遮挡、窗口适配和锁敌开销。
没有修改武器射速、伤害、敌人数量、运动频率或角色碰撞；没有更换任何生成图片。
更新源码，未导出新的 EXE。停止旧运行后从 Godot 按 F5，或重新运行“启动蜈蚣中文版.cmd”。

运行时
1. 玩家器官使用保留的 CanvasItem 和共享静态网格，通过顶点着色器执行原来的形变公式。
   保留 8×8 网格、翅膀振动、腹囊起伏、颚部回弹、牵引变形、透明度和固定根部。
   时间由游戏传入；暂停不会让着色器自行推进。敌方器官和装配预览保留原来的绘制顺序。
   网格按图集区域复用，纹理保持强引用，移除器官或离开战斗会释放 CanvasItem 和不用的几何缓存。
   诊断时可以设置 RBPEW_ORGAN_CPU=1 启动原 CPU 路径；日常运行默认使用 GPU 路径。
2. 首页、出击、设置、进化等静态菜单不再每帧重建隐藏战场，也不再绘制被遮住的旧飞船和整屏地面着色器。
   首页标本与装配预览保留各自的动画。暂停冻结战场图像，切页、恢复游戏和改变视口时仍立即更新。
3. 新 HUD 可见时跳过隐藏的旧 HUD 文本、布局和计数刷新；属性摘要只在数值或语言变化时重建。
4. 洞穴内的普通锁敌按目标优先级检测视线，不再为每个中间候选重复做墙体射线查询。
   保留相同优先级时的原顺序、护盾优先、随机雷达 RNG、修复与特殊雷达规则。
5. 器官与无人机采用实际视口裁剪；敌人和扫描视野不再依赖固定的 1440×900 边界。

显示效果
1. 雷达移到世界特效之上的独立 CanvasLayer，地图内容使用不透明底板，生成的骨甲边框保持原样。
   消除爆炸、护盾、弹幕或强闪光透进地图的问题。游戏菜单在雷达之上，敌方血条仍在战场层。
2. 小窗口雷达缩为 144×120，正常窗口为 180×150；标题与特效遮挡区域共用同一尺寸计算。
3. 绘制时同步实际视口中心，修复窗口变化后主体偏向右下的问题，验证至 2560×1080。
4. 跨屏射线和弯曲火焰按完整路径范围判断可见性，端点在屏外也不会把屏内危险隐藏掉。
   敌方持续攻击不消耗装饰特效配额；我方装饰特效仍有数量上限。

  主绘制平均 5.467ms → 4.982ms，减少约 8.9%；中位数 5.333ms → 4.951ms。
  RGBA 通道平均误差 0.0082 / 255；差异超过 16 的通道约 0.0132%，保留原素材和效果层次。
  敌人、弹体、装备和 RNG 未改变。记录：artifacts/render-snapshot-20261025.json。

菜单与锁敌：
  首页、出击、设置、进化连续 30 次处理均为 0 次隐藏世界重绘；首页独立标本动画继续。
  锁敌逆序候选样例由 32 次墙体射线降到 1 次；840 组遮挡/护盾/同优先级/随机选择对照全部一致。

整局性能的限制
开始、第一轮优化、最终各跑了一次正常主场景实时采样；其帧间隔参与模拟，不能视为完全一致的战况。
混装平均帧耗时分别为 15.58 / 14.59 / 18.66ms；交叉火力为 23.63 / 24.84 / 28.33ms。
最终实时采样更慢，因此这次不能声称整局 FPS 已提升，也不能保证密集战斗稳定 60 FPS。
渲染改动的收益只由上述同一画面的交替对照确认；敌人更新和密集特效仍有较高开销。
额外的 31 模块 / 64 高耐久敌人 / 256 弹体补充压力场景也未达到流畅帧率，保留完整报告用于后续定位。
CPU 与 GPU 压力运行的最终弹体数不同，不将两次整帧时间计算成优化百分比。
