岩层合批、虫群性能与真实加载进度 / 2026-10-21

本版保留黑白岩壁、碎裂边缘、A 方案露色矿粒和现有挖掘规则。

改动
1. 岩壁按样式合并轮廓、阴影、排线、裂纹与碎石描边；碎石面合并为一个三角网格。
   保留岩层块缓存，咬下岩石时仍只重建受影响的块。静止时沿用 Canvas 绘制命令。
2. 碰撞使用同一岩层的真实外轮廓，跳过岩石内部的细分边；行缓存有容量上限并在挖开后失效。
   中心穿入检测和滑动脱困仍使用原始填充几何，保留转弯、凹角、后退和身体跟随。
3. 虫群超过 24 只时，屏幕上小于 72px 且离画面中心超过 170px 的普通敌人可用共享材质的原画动画。
   位置、朝向、AI、碰撞和伤害每帧照常更新；近身、友军、受击、击退、牵引和死亡使用完整骨骼。
   骨骼权重、肢体裁切和静态三角化复用不可变结果，减少重复创建虫体时的计算。
4. 洞穴模式的连续矿脉替代旧版独立巨石矿场，保留地图节点、容器、守卫和其他任务机制。
   不再为不适合洞室的旧巨石反复搜索出生点。普通旧地图及直接生成矿石的机制继续保留。
5. 玩家出击走分阶段准备流程：虫体、任务、16 个矿区节点、首屏与相机边缘岩层、战斗效果、六种虫体。
   进度来自已完成的工作，阶段之间让出渲染帧；加载中停止模拟并拦截战斗输入。
   加载牌保留到完整战场与 HUD 画出、准备进度到达 100% 后才消失。重复点击和离开时的旧协程受令牌保护。
   保留同步 start_run 入口供独立检查使用；实际出击及导出验证使用异步 begin_run。
6. 在加载牌下面提交真实开火、命中、软体受击的绘制路径，提前完成首次 GL 渲染准备。
   预热用独立虫体和纯绘制数据，不产生子弹、伤害、掉落、击杀或奖励。
7. 右下角保留真实时间 FPS / ms / 最近 1 秒最慢帧，并增加 DC（整帧 draw call）。

实测条件与结果
Windows / Godot 4.6.3 Compatibility / GTX 1050 / 1440x900。
相同的 80 怪挖矿工况、六个 Gatling 模块，80 怪均保留，普通生产战斗、音频、掉落与原生绘制开启。
12 个场景暖机帧 + 240 个测量帧；输入模拟 dt 固定 1/60，但所有耗时与 FPS 都按真实时间计量。

旧 FPS 试玩基线：CPU 中位 30.296ms，p95 43.100ms；整帧中位 47.082ms，p95 64.811ms。
新实测：CPU 中位 10.758ms，p95 16.621ms；整帧中位 22.803ms，p95 31.849ms；最大 47.288ms。
末尾实际计数器约 40 FPS，25.3ms，近一秒最慢 34.2ms。
这表明该压力场景明显改善，不表示所有机器和战斗都能稳定 60 FPS。

仅渲染 A/B：冻结相同战场，不改碰撞/怪物数量，切换岩层显示。
合批前：显示岩层 628 DC，隐藏岩层 331 DC，岩层增量 297。
合批后：显示岩层 368 DC，隐藏岩层 331 DC，岩层增量 37（约减少 87.5%）。
这是岩层合批前后的局部对照，合批前这次对照已使用新的远景虫群渲染，不冒充旧发行版的 DC 读数。

原生测量曾在首次开火/命中帧分别出现约 200ms / 100ms 尖峰。
预热实际绘制后，同一固定帧为 25.398ms / 34.919ms。
准备耗时受首启缓存、任务与机器占用影响；界面展示实际进度，不提供虚构的剩余秒数。
