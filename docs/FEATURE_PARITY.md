## 最新测试入口

- `python tools/run_checks.py`：20个有界检查套件；任何引擎脚本错误均判失败。
- `tools/test_navigation_input.py`、`test_build_input.py`、`test_operations_input.py`、`test_real_input.py`：通过X11真实鼠标/键盘操作，不调用游戏函数代替用户操作。
- `tests/test_persistence.gd`：在独立新进程中核对真实研究购买后的存档。
- `tests/test_fresh_run.gd`：新存档，仅自动作出移动、瞄准、选择和合法建造决策；不注入装备、血量或结果。
- `RBPEW_BALANCED_FIXTURE=1 RBPEW_ENDLESS_SECONDS=900 python tools/test_campaign_parallel.py`：六任务后期装备夹具，正常伤害，无强杀、跳时或胜利回调。
- `tests/test_stress_gui.gd`：真实1440×900窗口、60模块、固定随机种子和鼠标位置、8秒预热后30秒满编测量。

报告全部位于 `artifacts/`。`pre-scrap-*`为恢复物理废料前的历史报告，不能当作最终代码证据。截图来自实际Godot窗口。菜单截图流程有明确注入装备/货币及强制结果，仅用于显示验收；自然胜败由其他测试证明。

## 性能证据与限制

`paired-performance-report.json`是同一功能范围、同一软件渲染配置下的优化对照：13.77→25.20 FPS，P95 92→56ms。独立600步比较及24个战斗状态快照验证空间索引与原顺序一致；图集实验变慢，已撤回。

后来补回源装饰、引擎、独立掉落物等内容，不能继续把25.20 FPS当作最终范围的性能。最终 `gui-stress-report.json` 为完整拉伸、正确加法混合及世界/局部粒子空间下20.53 FPS、P95 58ms，136敌人/121弹丸/78发射器峰值。较早的23.50 FPS测量尚未加入全部拉伸；13.93 FPS测量仍含后来修复的材质/空间错误，均不能代表最终范围。共享着色器及静态拉伸专用程序单独没有带来显著整体帧率提升。该环境只有llvmpipe软件渲染，结果有波动，未达到60FPS；离屏引擎仍按源AlwaysSimulate执行。
