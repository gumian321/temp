本次明显减少了岩壁绘制与碰撞开销，并拆分了换区准备工作。黑白岩石、碎裂边缘、彩色露矿、挖矿掉落、身体跟随和怪物使用新通道继续保留。

主要实现
1. 岩壁描线使用每段两个三角形的抗锯齿网格，沿用原轮廓、线宽、颜色和绘制顺序。
   固定画面诊断中，岩壁带来的三角形增量从约 14.3 万降到约 3.1 万；这部分开销并非只看 draw call 就能判断。
   0.65 / 1.0 / 1.75 三档缩放的原描线与网格对照图已留存。抗锯齿过渡存在小幅像素差别。
2. 每块岩层内部缓存 4×4 小区域的顶面、矿粒和描线几何，挖掘只重算受影响区域，再拼接缓存。
   啃挖裂纹单独更新；未变化的样式保留 GPU 网格。相机前方分帧准备，避免移动到边界才集中构建。
3. 碰撞继续使用同一岩石轮廓。扫掠直接使用暴露边，内置几何函数处理圆角；只为最近命中创建结果。
   挖掘只清理受影响的碰撞行和受阻区域，已经验证安全的空地证书继续有效。
   原有完整穿入恢复仍保留，凹角、贴墙、窄路后退及身体跟随有独立回归。
4. 寻路的冷数据准备有单帧时间与数量预算；挖穿后先标记受影响区域，再分帧更新。
   远处怪物保留移动、碰撞、计时和伤害更新，使用局部避墙；进入附近后恢复完整寻路。
5. 新矿区、敌人队形与任务波次先分帧准备完整碰撞范围，再生成。
   生成队列计入任务存活状态，避免尚未生成的波次被判定已清空；守卫绕行以实际可站立的出生点为中心。
6. 未受击且完全静止的软体弹簧跳过零值运算，维持原时间步累计。受击、击退和牵引继续完整计算。
   敌人血条细线合批；近身与受击的虫体细节及现有挖掘效果保留。
