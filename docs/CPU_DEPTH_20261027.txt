当前默认开启的精确优化
1. AI 武器输入：每次同步敌人循环重建按核心 ID 缓存的旋转速度、允许误差、射程与武器类型。
   所有炮口角度与冷却计时仍逐次更新；完成这些强制更新后，才可依据原来的精确射程判定跳过后续无效计算。
   普通弹丸仍使用碰撞之后的实际位置到目标的距离，连续武器仍使用原 delta；不混用两种距离。
   敌方无人机数量按 bay 在本次敌人循环中延迟统计，并在生成时更新；下一次循环重新读取当前列表。
   开关 RBPEW_ENEMY_CORE_FRAME；RBPEW_LEGACY_ENEMY_CORE_FRAME=1 强制原路径。
2. AI 组件：本次敌人循环缓存 source_id 对应的组件 Array 身份与第一个 KamikazeTrigger。
   每次读取以 is_same 校验 Array 身份，替换 Array 时重建；保留重复组件的第一个匹配项。
   每次循环清空，循环外继续直接 source_component 查找；没有给存档 actor 添加缓存字段。
   开关 RBPEW_ENABLE_AI_COMPONENT_FRAME；RBPEW_LEGACY_AI_COMPONENT_FRAME=1 强制原路径。
3. 空间索引构建：完整 rebuild 已清空查询缓存后，内联原 insert 的桶插入过程。
   保留原 cell 坐标表达式、插入顺序、UID、死敌、友军、范围与边界扩展；每次 rebuild 只读取一次相同核心的护盾类型。
   false 也作为有效缓存值，不把非护盾核心反复当作缓存未命中；下一次 rebuild 读取实时核心数据。
   开关 RBPEW_ENABLE_SPATIAL_BUILD；RBPEW_LEGACY_SPATIAL_BUILD=1 强制原路径。
4. 近处碰撞探测：对有界长扫掠先检查局部原始轮廓。只在证明命中足够近时接受结果，否则完整回退。
   正式默认范围为半径 1..64、扫掠距离 32..4096、坐标绝对值小于 32768；原 delta、长度平方、轮廓时间与完整命中字典保留。
   局部邻域为 32 像素，接受距离严格小于 24 像素的接触；相等时间保持原遍历顺序。
   开关 RBPEW_ENABLE_NEAR_CONTACT_PROBE；RBPEW_LEGACY_NEAR_CONTACT_PROBE=1 强制原路径。
5. 地图观察者：只略过严格位于已测试头部观察圆内部的观察圆。
   使用原 Vector3 中心/半径，额外留 4 像素裕量；超出有界半径或坐标时继续原始观察者路径。
   开关 RBPEW_ENABLE_ORBIT_OBSERVER_PRUNING；RBPEW_LEGACY_ORBIT_OBSERVER_PRUNING=1 强制原路径。
